# INFO2180 — Project 1

> A full PHP web application combining HTML, CSS, JavaScript, and server-side scripting.

Built for **INFO2180 — Web Programming I** at the University of the West Indies, Mona.

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (jQuery)
- **Backend:** PHP
- **Database:** MySQL

## Features
- User-facing interface with form-driven interaction
- Server-side data processing via PHP
- Database persistence with MySQL
- AJAX-powered partial page updates

## Run Locally
```bash
# Requires PHP and MySQL installed locally
php -S localhost:8000
```

Visit `http://localhost:8000` in your browser.
